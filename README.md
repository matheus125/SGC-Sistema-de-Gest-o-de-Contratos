O SGC — Sistema de Gestão de Contratos, uma plataforma web destinada à gestão completa do ciclo de vida contratual.

O sistema deverá centralizar:

contratos;
fornecedores;
unidades;
gestores;
fiscais;
suplentes;
aditivos;
documentos;
garantias;
fiscalizações;
ocorrências;
pendências;
planos de ação;
alertas;
notificações;
riscos;
relatórios;
indicadores;
auditoria.

O objetivo final é transformar dados contratuais em informação operacional e gerencial para apoio à tomada de decisão.
